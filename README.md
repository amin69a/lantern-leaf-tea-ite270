# Lantern Leaf Tea

ITE 270 · Module 8 · Final: Your Shop in Motion

A single-page fictional campus bubble tea shop based on the Week 3 **Calm, Bright, Responsive** plan. Adapted from the instructor's Bakery Motion Lab starter. No installation or build is needed.

## Run

Open `index.html` in Chrome, or serve this folder with a static HTTP server. All assets use relative paths, so the project works in a GitHub Pages repository or subfolder. The order is a temporary demonstration, not a purchase.

## Explore

- Hover, Tab, and press controls and menu cards.
- Watch the four-word headline and the two SVG hanging objects.
- Scroll through the menu and the three preparation steps in either direction.
- Add a drink and open the bag for its quantity and demo total.
- Press **M** or the **Motion X-ray** button; select **⅒×** to inspect the two chained order animations.
- Use **Pause motion** in the top bar. The footer also has **Use reduced motion** and **Replay headline** controls. Device reduced motion takes priority over the page switch.

## Assignment evidence

`MOTION-LOG.md` follows the starter's template and documents every shop animation, all three easing curves, the actual local Chrome X-ray observation, and the honest checklist. The supplied instructor `motion-xray.js` is kept for the demonstration.

## GitHub Pages

Upload the files in this folder to the root of a public repository (or a folder on an existing Pages site). In the repository's **Settings → Pages**, choose **Deploy from a branch**, then the appropriate branch and folder, and save. Wait for deployment and open the resulting URL. Do not use a `file:///` or localhost address as the live submission link.

The assignment asks for three links: the live GitHub Pages page, the GitHub repository containing `MOTION-LOG.md`, and a 45–90 second screen recording with the student's own narration. A ZIP alone does not replace those links.
