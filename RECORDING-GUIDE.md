# Part 4 recording guide — 45 to 90 seconds

Record the **published GitHub Pages page** in Chrome with your own voice. Aim for 75–85 seconds. Practice once before recording. Keep the X-ray open during the demonstrations, and keep the three spoken sentences synchronized with their motions.

## Prepare before recording

1. Open the live site. Open Chrome DevTools → Rendering so the reduced-motion dropdown is ready. For a clearer page, undock DevTools or keep it narrow.
2. Open X-ray with **M**. Start at **1×**. Make sure the top-bar button reads **Pause motion** and device reduced-motion emulation is off.
3. Prepare to show the headline, the hanging objects, and an Add to order button. The footer has Replay headline if needed; reload also replays it.

## Spoken script and actions

**0–8 seconds — introduce the project and X-ray.**

“This is Lantern Leaf Tea, my campus bubble tea shop. Its personality is calm, bright, and responsive. This is the Motion X-ray.”

**8–25 seconds — reload or replay the headline. Read while it arrives.**

“When the page loads, each headline word changes its vertical offset and opacity over 650 milliseconds, staggered by 120 milliseconds, with ease-out, so the visitor reads the invitation in order.”

**25–42 seconds — point to the hanging lantern while it moves.**

“When the storefront loads, the lantern changes its rotation between minus and plus four degrees over repeating 4.8-second cycles with ease-in-out, so the shop feels gently alive. It pivots at the hook.”

**42–63 seconds — scroll to the menu; select X-ray ⅒×, then add one drink.**

“When I activate Add to order, a drink copy changes its position, scale, and opacity over 450 milliseconds with ease-in-out, so I can see where it went. Only after it finishes does the badge pulse for 180 milliseconds. The order is also announced through aria-live.”

**63–73 seconds — return X-ray to 1×; press top-bar Pause and Play.**

“Pause stops both hanging loops. Play resumes them.”

**73–85 seconds — DevTools Rendering: set prefers-reduced-motion to reduce. Show X-ray 0 animations and visible content.**

“With reduced motion on, the loops and travel stop. The content stays visible, and adding a drink still updates the order and its message.”

## Before submitting

- Check that the recording is between **45 and 90 seconds**, the page is readable, and your voice is audible.
- Show the actual X-ray, at least one slow-motion animation, reduced motion, and the site's Pause button.
- Upload the recording to Canvas Studio or a location anyone in the course can access. Test its link while signed in as appropriate; avoid a private-only file link.
- Submit the live Pages URL, repository URL, and recording URL. The prepared script is not the required recording.
